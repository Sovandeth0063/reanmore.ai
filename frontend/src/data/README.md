# 📚 Frontend Demo Datasets

This directory contains only the demo worksheet fixtures used by the home view and the
scanner demo. Tutoring content (steps, options, expected answers, hints and visuals) is
generated by the backend LLM prompts — there is no hardcoded answer bank in the app.

---

## 📁 Files & Purpose

| File | Purpose | Description |
| :--- | :--- | :--- |
| **`mockProblems.ts`** | 📑 Demo Worksheets | Sample worksheet problems with bilingual text used by the home view and scanner demo. |

---

## 🔄 Content Flow

1. **Tutoring (all subjects)**:
   - Queries and scanned homework are sent to the orchestrator, which plans every step,
     option, expected answer and visual through the configured LLM prompts.
2. **No offline answer fallback**:
   - If the LLM is unavailable, the backend returns a retry message instead of serving
     pre-written answers. The UI never falls back to a hardcoded step/answer catalogue.
